# Rachel's Universe

IMPORTANT: I have attached a photo of Rachel. Use this photo ONLY as a visual reference for Rachel's face in the badminton character. Create a stylized, playful oval-face version of her rather than a photorealistic recreation. Preserve recognizable facial features while keeping the character consistent with the artistic style of the website. Do not use the photo elsewhere on the website unless explicitly instructed.

Create a highly creative, interactive, visually stunning birthday website titled:

# HAPPY BIRTHDAY RACHEL 🐈🎨🎂

This website is a birthday gift **from me to Rachel**.

Rachel is:

* Extremely creative
* Works in art
* Loves cats
* Loves sports
* Extremely competitive at badminton
* Slightly unfunny 😂
* Someone who deserves a completely ridiculous, personalized birthday experience

The entire website should feel like entering **Rachel's own universe**.

The central visual identity should be:

# 🐈 CATS × 🎨 ART × 🏸 BADMINTON × 🎂 BIRTHDAY CHAOS

Do NOT make this look like a generic birthday website.

It should feel like an interactive digital art piece that someone spent an unreasonable amount of time creating specifically for Rachel.

---

# ⭐ CORE CREATIVE DIRECTION

The entire website is secretly a **CAT WORLD**.

Cats should exist throughout the experience.

Not just in one section.

They should randomly:

* Walk across the screen
* Crawl from behind cards
* Sit on buttons
* Sleep in corners
* Peek from the edges
* Chase floating objects
* Knock things over
* Appear behind text
* Run across the bottom of the screen
* Occasionally interrupt the user

Some cats should be subtle.

Some should be ridiculous.

Some should be interactive.

The website should occasionally surprise the user with:

> 🐈 “meow.”

or:

> “Rachel's cat has entered the website.”
